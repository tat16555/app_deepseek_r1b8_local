# deepseek local
Public

แชทบอทที่ใช้ **Ollama** และ **Langchain** เพื่อสร้างแอปพลิเคชันที่สามารถตอบคำถามโดยอัตโนมัติ โดยมีลักษณะการทำงานดังนี้:

- **Ollama**: ใช้ในการประมวลผลคำถามและให้คำตอบ
- **Langchain**: ใช้เพื่อสร้างการเชื่อมต่อระหว่างระบบแชทและโมเดล
- **Chainlit**: ใช้ในการจัดการแชทอินเทอร์เฟซและตอบคำถาม

## คุณสมบัติ
- รองรับการตอบคำถาม
- ใช้ **DeepSeek** โมเดลจาก Ollama
- สตรีมคำตอบจากโมเดลแบบทีละตัวอักษร
